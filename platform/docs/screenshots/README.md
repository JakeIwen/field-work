# Screenshots

All applicant, company, job, conversation, email and document data is synthetic, generated by `npm run demo`. Recaptured on 2026-11-09 (2026-11-09T00:43:45.847Z) at 1440×900 (desktop) and 390×844 (phone), at CSS/device scale 1 to keep the PNGs small. All views use the saved Rosewood Slate theme (neutral hue 360, brand hue 240, focus hue 70, color intensity 1.15), in the Soft/Dark modes shown. Dates are relative to each demo run.

From `platform/`, run `npm run demo` and open the loopback URL it prints. The demo uses disposable `.local/dev/demo-*/` sources and SQLite data; it never opens a personal database or the companion. It is read-only: agents, model discovery, sending, scheduled integrations and workflow starts are disabled. Theme mode and preview still work locally. The demo shell disables external links and window opening; the backend rejects external sockets and the companion port. Hosted-board URLs use a standard Greenhouse host with the deliberately fictional `northwindexample` board token so the normal Autofill filter and controls are exercised; no live board is consulted. The listing pull is intentionally paused with saved progress, not executing a search. The saved autofill artifact is produced by the real planner from in-memory synthetic form responses; it is not evidence of a real employer form-fill run. Its board token is deliberately fictional.

To retake all screenshots, with the existing clean-browser MCP service running at `http://localhost:8931/mcp`, run `npm run demo:screenshots` from `platform/`. This builds the app, starts its own temporary backend, uses that isolated browser service (never launches a browser), blocks state-changing and external browser requests, captures the views, records network results in `capture-network.json`, and closes its backend. No application data or settings are changed. If the service is unavailable, run the configured browser MCP service health check; do not launch a separate browser. For an interactive demo, Ctrl+C stops the backend.
